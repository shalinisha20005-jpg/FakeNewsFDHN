# FakeNewsFDHN

## Fake News Detection Using FDHN-Inspired Fuzzy Deep Learning

This project explores six-class claim classification using the LIAR dataset and an FDHN-inspired fuzzy deep learning model.

### Dataset
The project uses a cleaned version of the LIAR dataset. Dataset labels represent fact-checker truthfulness ratings.

### Model
- Text feature extraction using TF-IDF and Logistic Regression
- Numerical feature processing and fuzzy membership layers in the FDHN-inspired model
- Six-class prediction

### Evaluation
The cleaned test evaluation previously achieved approximately 50.55% accuracy on 2,289 samples.

This is an experimental research project, not a reliable standalone verifier of real-world news.

### Technologies
- Python
- Pandas
- NumPy
- Scikit-learn
- PyTorch
- TF-IDF
